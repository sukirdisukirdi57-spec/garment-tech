Status: catatan audit; database tidak diubah.

| Kode | Hasil pencocokan manual | Tindak lanjut |
|---|---|---|
| E007 | Manual menyebut Motor overload dan kondisi kepala mesin diganti. | Perbarui temuan audit lama; pertahankan data yang didukung manual. |
| E071 | Penyebab mencakup konektor motor terlepas, rangkaian deteksi arus rusak, atau tidak ada umpan balik arus. Langkah yang tercantum memeriksa konektor output motor. | Lengkapi catatan bahwa diagnosis rangkaian memerlukan teknisi. |
| E072 | Overload terjadi saat thread trimmer beroperasi; tidak ada langkah pemeriksaan khusus pada baris manual. | Jangan mengarang solusi. |
| E303 | Sinyal meniscus sensor tidak terdeteksi; manual menyebut pemeriksaan pengaturan model kepala dan konektor encoder motor. | Pertahankan sebagai draf sampai terjemahan istilah dan varian diverifikasi. |
| E704 | Versi sistem tidak cocok dengan pengaturan kepala mesin; manual menyebut penulisan ulang versi yang sesuai. | Batasi sebagai prosedur servis resmi. |
| E922 | Poros utama tidak beroperasi sebagaimana mestinya; tidak ada langkah pemeriksaan spesifik pada baris tersebut. | Rujuk diagnosis ke teknisi kompeten. |
| E924 | Manual menyebut kerusakan motor driver. | Diagnosis dan penggantian hanya setelah pemeriksaan teknisi. |

Catatan keselamatan:
- Matikan dan isolasi daya sebelum pemeriksaan fisik.
- Pemeriksaan rangkaian listrik, PCB, driver, dan pengubahan versi sistem dilakukan teknisi kompeten.
- Kecocokan manual dengan varian fisik mesin tetap harus dipastikan.

Dokumen ini mencatat hasil pembandingan teks manual, bukan sertifikasi teknis.
